# Clamp V1 purchase/build list

The exact quantities and dimensions are in **BOM_CLAMP_V1.csv**. Use this for the two-jaw prototype; the old five-finger BOM is not the active gripper build.

Already marked ordered in the repository: ELEGOO ESP32, positional MG996R, EBOOT MP1584EN, M3 assortment. This is an order-record flag, not confirmation that those parts arrived. The battery and balance charger are not marked ordered. The earlier 50 lb line entry is stale: user selected DWLIFE 120 lb, 150 m, eight-strand line.

Purchase now for the prototype: selected-envelope OVONIC 2S battery, balance charger, Pololu D24V50F5, PETG and TPU95A if absent, M2 hardware, suitable M3 inserts/nyloc nuts, foam, ties, fuse holder and wiring. Measure parts before printing all structural pieces. Round horn, inserts and metal-ring supplier must be checked before treating their mating dimensions as frozen. The battery pack listing uses tolerances; the tray is sized for its maximum published dimensions.

This list is finalized at the prototype specification/quantity level. The entire product is **not** a fully qualified purchase release: winch guide eyelets/springs, motor encoders, exact rings and actual component measurements remain open. Existing motor/shield/limit-switch/camera selections stay in SHOPPING_LIST.md; their prior checked records have not been converted into confirmed deliveries. Do not order legacy tentacle tendon/finger hardware for this stage.
